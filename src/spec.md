# Specification

## Summary
**Goal:** Expand the store with a new Bundle category, refresh the homepage hero copy with “Farm the Aura”, add subtle Aura MC branding animations, and display the cart subtotal in ₹ in the header.

**Planned changes:**
- Add a fifth top-level store category option labeled “Bundle” alongside Lifesteal, Token SMP, Aura SMP, and BoxPVP, with navigation to a matching category page route.
- Add a new “Bundle” catalog category containing exactly one purchasable item priced at ₹1750, listing: “5🔑 Top Keys”, “3 Months Top Rank”, “750🪙 Coins”, “10M 💸 Money”, plus the note “Valid in any 1 realm”.
- Update the homepage hero section to prominently include the phrase “Farm the Aura” in a high-quality display font style aligned with the site’s premium/professional aesthetic.
- Add subtle, professional animations to Aura MC branding elements (logo and/or “Aura MC” text) visible on the homepage and in the persistent header.
- Update the header cart entry point to show the current cart subtotal formatted in INR (₹) next to the cart button when the cart is not empty, while keeping the existing item count badge.

**User-visible outcome:** Users can browse and purchase a new Bundle product (₹1750) from a new Bundle category, see “Farm the Aura” on the homepage hero, notice subtle Aura MC brand animations on key site areas, and view the cart subtotal in ₹ in the header when items are in the cart.
